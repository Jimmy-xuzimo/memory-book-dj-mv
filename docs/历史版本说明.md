# 《把回忆拼好给你》DJ 版 · 奇想绘本动画首版

1920 × 1080 / 30 FPS / 2371 帧。原 WAV 79.018666667 秒，全曲覆盖，不截断；视频帧网格为 79.033333333 秒。

## 预览和运行

已安装环境：Node 24.21.0，Remotion 4.0.536，React 19.2.3。

```powershell
npm ci
npm run dev
```

选择 `MemoryBook`。`Studies` 中有角色关节、地球、聊天与纸鲸的独立场景。

```powershell
npm run lint
npx remotion render MemoryBook memory-book.mp4 --codec=h264 --crf=16 --image-format=png --audio-bitrate=320k
```

本机渲染使用已安装 Chrome，避免等待下载浏览器；若需要指定：

```powershell
npx remotion render MemoryBook memory-book.mp4 --codec=h264 --crf=16 --image-format=png --audio-bitrate=320k --browser-executable="C:\Program Files\Google\Chrome\Application\chrome.exe" --concurrency=4
```

## 编辑位置

| 文件 | 用途 |
|---|---|
| `src/Timeline.tsx` | 40 个各自可选的镜头实例，起止时间明确写在 JSX 中 |
| `src/data/shots.json` | 批准的 v2 分镜及原始镜头时段、歌词引用与导演要求 |
| `src/Worlds.tsx` | 六个连续世界的场景、角色调度和道具动作 |
| `src/Character.tsx` | 统一角色矢量关节、表情、走路、牵手、坐姿、挥手及转面 |
| `src/Art.tsx` | 纸船、树、云、房屋、照片、星星与灯等绘本素材 |
| `src/MV.tsx` | 遮罩、5 次翻页、镜头运动、全曲音频和全局字幕 |
| `src/motion.ts` | 缓动、种子函数、确定性的运动和音频能量访问 |
| `src/data/captions.json` | 24 条完整原始 SRT 文本及毫秒/帧边界 |
| `src/data/bass-pulse.json` | 原音频 35–160 Hz 能量的正向增量及短衰减，辅助少量纸片动效 |
| `src/data/envelope.json` | WAV 每帧对应区间的 RMS 能量 |

| `public/reference.png` | 原角色参考图的逐字节复制 |

修改剪辑时间时，请同步 `Timeline.tsx` 的实例时段、offset 与 `shots.json` 的镜头时段；字幕与音轨采用独立的全局时钟，不随跨镜头变化重置。

## 动画和素材来源

本版的角色、背景和道具是根据用户参考图与 v2 方案编写的 SVG 矢量重绘，非 AI 生成插画；转面是同一矢量模型的简化转面。纸纹是固定随机种子产生的本地纹理。没有使用第一阶段示意图、照片裁片轮播或生成视频。

头身、脸部和衣服使用同一套结构；女主发夹位于角色自身左侧，正面在画面右侧、背面在画面左侧。地球镜头以北极上方的绘本视角表达西向东的同向行走，光源固定右侧，昼夜遮罩不随人物转动；地球地理轮廓为绘本化示意。

所有动画来自帧号、固定数值和种子函数，不使用真实时间 CSS 动画或运行时随机数。呼吸、摆臂、眨眼、头部微动、裙摆及抽绳有各自的相位；镜头有缓入缓出；翻页不压缩总时长。

## 字幕、音乐和字体

- 原 SRT 24 条，文本逐字保留，包括疑似错字；没有自动修订歌词。
- 显示区间是 `[ceil(startMs×30/1000), ceil(endMs×30/1000))`。跨镜头连续，入退场限制在各条范围内。
- 49.600–52.100 秒与 78.300 秒之后不添加歌词；片尾出现的是歌曲标题。
- 音频未做变速、裁尾、自动音量变化或另配音效。编码为 AAC 320 kbps。
- 低频能量分析只用于辅助动效；没有确认精确 BPM、下拍、逐字演唱时点或 63.300 秒梦醒对应的具体演唱字。
- 中文优先调用本机 `STKaiti` / `KaiTi`，后备 `Microsoft YaHei`。不随工程复制商业字体；移到其他电脑时需安装有权使用的同类字体并重新检查。
