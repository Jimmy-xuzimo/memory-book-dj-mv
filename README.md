# 《把回忆拼好给你》DJ 版 · 手绘回忆动画 MV

**© 2026 Zimo Xu（Jimmy-xuzimo）。版权所有，保留所有权利。**

使用 Remotion 制作的 Q 版二维手绘动画 MV，以回忆手账、遮罩转场、青春恋爱场景和手写歌词贯穿全曲。当前版本为 **v9**，早期版本源码与素材一并保留。

## 当前版本

- 1920 × 1080，30 FPS，2371 帧；原始音频约 79.019 秒，保留完整尾音。
- 40 个连续镜头；按帧号驱动角色动作、镜头、转场和字幕。
- v9 修正「直到梦突然醒来」，开场男生自然垂臂，影院爆米花使用不规则颗粒和堆叠。
- 延续广场反向步态、金色烟花、回忆胶片、梦境渐白与书中照片拼合。
- 歌词通过手写笔画路径显示，不依赖系统字体。24 条字幕保持原 SRT 时间，仅按所有者要求更正指定文字。

## 运行与导出

需要 Node.js ^20.19.0、^22.13.0 或 >=24。

```sh
npm ci
npm run dev
```

Studio 默认端口 4466，选择 `HandDrawnV9 / MemoryBookV9`。

```sh
npm run lint
npm run render:v9
```

导出位置：`out/把回忆拼好给你_DJ_自然垂臂与爆米花精修_v9.mp4`。
依赖和构建产物不纳入 Git。成片可以从源码重新渲染。
